## Today's practice phrases

Je suis japone.
Tu es un homme.
Vous etes un homme.
On est les amis.
Ile est un homme.
Elle est une femme.
Ils sont humaines.
Nous somme les amis.

## Correction and explanation

| Original | Corrected | Note |
|---|---|---|
| Je suis japone. | Je suis japonais. | "japone" n'existe pas. La nationalité s'écrit **japonais** (masc.) ou **japonaise** (fém.). Pas d'article avec les nationalités après *être*. |
| Tu es un homme. | Tu es un homme. ✓ | Correct ! |
| Vous etes un homme. | Vous **êtes** un homme. | L'accent circonflexe est obligatoire : *ê-t-e-s*. |
| On est les amis. | On est **des** amis. | *Les* désigne des amis déjà mentionnés. *Des* est plus naturel pour une affirmation générale. |
| Ile est un homme. | **Il** est un homme. | Faute de frappe : *Ile* → *Il*. |
| Elle est une femme. | Elle est une femme. ✓ | Correct ! |
| Ils sont humaines. | Ils sont **humains**. | *Ils* est masculin pluriel, donc l'adjectif prend la forme **humains**, pas *humaines* (féminin pluriel). |
| Nous somme les amis. | Nous **sommes** des amis. | Il manque le **-s** final : *sommes*. Même remarque sur *les* → *des* que pour *on*. |

### Key points to remember

**Conjugation of *être* (to be):**

| Pronoun | Form | Pronunciation note |
|---|---|---|
| je | suis | /sɥi/ |
| tu | es | /ɛ/ |
| il / elle / on | est | /ɛ/ — same sound as *es* ! |
| nous | **sommes** | don't forget the double-m and the -s |
| vous | **êtes** | the accent on ê changes the sound: /ɛt/ |
| ils / elles | sont | /sɔ̃/ |

The tricky part: *es*, *est*, and the *e* in *êtes* all share a similar /ɛ/ vowel sound, but they are spelled differently. Listening carefully to the surrounding words (especially the pronoun) is the key to distinguishing them.

**Adjective agreement:**
French adjectives agree with the subject in gender and number.
- *Il est japonais.* (masc. sing.)
- *Elle est japonaise.* (fém. sing.)
- *Ils sont japonais.* (masc. pl. — or mixed group)
- *Elles sont japonaises.* (fém. pl. — all female)

**Article choice (*des* vs *les*):**
- *des amis* = some friends (indefinite, general)
- *les amis* = the friends (definite, already known to both speaker and listener)
