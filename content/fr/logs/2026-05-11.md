Today I started learning basic verbs in real sentences.

I'm skimming some YouTube videos for children. Just watching these videos can be boring for adults, so I first extract transcripts and analyze and complement them with LLMs. Then, I find good examples for learning how to use verbs. If I feel curious about the situation or pronunciation, I check the video.

I found this video useful for learning how to use "aller" to describe the near future.
