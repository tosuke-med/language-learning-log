Aujourd'hui, j'ai commencé à apprendre les verbes de base dans de vraies phrases.

Je parcours des vidéos YouTube pour enfants. Regarder ces vidéos peut être ennuyeux pour les adultes, donc j'extrais d'abord les transcriptions et les analyse avec des LLMs. Ensuite, je trouve de bons exemples pour apprendre comment utiliser les verbes. Si je suis curieux de la situation ou de la prononciation, je regarde la vidéo.

J'ai trouvé cette vidéo utile pour apprendre comment utiliser « aller » pour décrire le futur proche.
